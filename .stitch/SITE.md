# SkillBridge / DumbDuck Student PWA Companion

DumbDuck is a mobile-first Progressive Web App (PWA) designed as an all-in-one academic companion for university students, styled using the UI-UX Pro Max design intelligence system.

## 1. Project Vision
Consolidate activity tracking, resume building & AI analysis, AI academic chatbot with camera image solving, weekly timetable & calendar manager, and student profile management with achievement badges into a seamless mobile PWA with elevated glassmorphism aesthetics.

## 3. Technology Stack
- Core: React 18, Vite, Tailwind CSS, Framer Motion, Recharts, Zustand
- AI: OpenAI GPT-4o Multimodal Vision & Text + Fallback Engine
- Database/Auth: Supabase JS + LocalStorage Persistence
